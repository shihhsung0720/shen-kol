# 品牌資料大腦 (`brand-brain/`)

## 為什麼存在

解決 3 個內容生產痛點：
1. 腦子有東西、沒組織 → AI 餵不到
2. 寫過的話 / 拍過的內容、找不到舊素材
3. AI 寫出來太通用、像隨便哪個牌子

## 設計原則

- **知識層（人寫的 markdown）和狀態層（之後的 JSON / 進度）分開**。本資料夾屬知識層。
- **AI 只讀不寫**：所有檔案由 Kai 手填、AI 不可主動修改、不可編造數字 / 案例 / 口頭禪。
- **規則寫在資料層、不寫進 prompt**：能用 schema / 缺欄位攔截、不靠 AI 自律。

## 檔案地圖

| 檔 | 角色 | 變動頻率 |
|---|---|---|
| `index.md` | 載入規則 + 更新觸發 | 低（新增資料層才動） |
| `brand.md` | 品牌靈魂（7 節） | 中（季度級） |
| `products.md` | 產品矩陣 | 高（每次新品 / 改版） |
| `cases.md` | 過往 Reels + KOL 合作案例 | 高（每週累積） |
| `brand-summary.md` | 速查精簡版（~2KB） | 同 `brand.md` 同步 |
